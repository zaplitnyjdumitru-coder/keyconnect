# KeyConnect

Настольный клиент для VPN-ключей в духе v2rayN / Hiddify. Работает на Windows, macOS и Linux.
В качестве ядра использует [Xray-core](https://github.com/XTLS/Xray-core): при первом подключении программа сама скачивает его с GitHub.

## Что умеет
- Ключи `vless://` (включая REALITY + Vision), `vmess://`, `trojan://`, `ss://` (в том числе Shadowsocks-2022)
- Транспорты tcp, ws, grpc, httpupgrade, xhttp, а также TLS и REALITY
- Подписки по ссылке `https://…` (base64 или обычный список), обновление в один клик
- Настоящий тест задержки: для каждого сервера поднимается временный Xray и делает запрос к generate_204
- Включение системного прокси (Windows, macOS, GNOME, KDE)
- Режим «Россия напрямую»: домены .ru/.рф/.su, geosite:category-ru и geoip:ru идут мимо VPN
- Локальные порты SOCKS5 127.0.0.1:10808 и HTTP 127.0.0.1:10809

## Запуск
Нужен Python 3.9+ со стандартным tkinter. Сторонние библиотеки не требуются.

```
python main.py
```

1. Скопируйте ключ или ссылку на подписку и нажмите «Вставить ключ» (или Ctrl+V).
2. Выберите сервер и нажмите «Подключить» (или дважды щёлкните по нему).

Консольный режим без окна:
```
python main.py "vless://..." --sysproxy --ru-direct
python main.py "https://sub.example.com/abc" -n 3
```

## Где лежат данные
- Windows: `%APPDATA%\KeyConnect`
- macOS: `~/Library/Application Support/KeyConnect`
- Linux: `~/.config/KeyConnect`

В `data.json` хранятся серверы, подписки и настройки, там же меняются порты.
Xray-core лежит в подпапке `xray/`. Если GitHub недоступен, положите туда `xray`/`xray.exe` вручную вместе с `geoip.dat` и `geosite.dat`.

## Ограничения
- Работает в режиме системного прокси. Браузеры и большинство программ его подхватывают, но игры, некоторые мессенджеры и консольные утилиты могут идти мимо. Чтобы туннелировать весь трафик, нужен режим TUN (wintun / sing-box).
- Нет поддержки hysteria2, tuic и ss с плагинами, а также подписок в формате Clash/sing-box.

## Сборка установщика (KeyConnect-Setup.exe и .dmg)
Установщики собирает GitHub Actions по файлу `.github/workflows/build.yml`:
1. Загрузите содержимое этой папки в репозиторий на GitHub, в ветку main.
2. Сборка запустится автоматически и займёт около 5–7 минут.
3. Готовые файлы появятся во вкладке **Releases**:
   - `KeyConnect-Setup.exe` — установщик для Windows. Ставит программу без прав администратора, создаёт ярлык на рабочем столе и в меню «Пуск», удаляется через «Параметры → Приложения».
   - `KeyConnect-macOS.dmg` — для Mac на Apple Silicon.

Xray-core уже встроен в установщики, поэтому при первом запуске ничего не скачивается.
Чтобы выпустить новую версию, достаточно отправить изменения в main.

Установщики не подписаны. На Windows SmartScreen при первом запуске покажет «Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае». На Mac откройте программу через правый клик → «Открыть» или выполните `xattr -cr /Applications/KeyConnect.app`.
